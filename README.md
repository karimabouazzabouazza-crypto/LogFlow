# LogFlow

## Project Description
LogFlow is a Java application that reads and processes log files using a pipeline architecture.

## Features
- Reads log entries from a file.
- Parses log records.
- Processes records through pipeline stages.
- Prints processed records to the console.
- Handles processing exceptions.

## Technologies
- Java
- IntelliJ IDEA

## How to Run
Run the Main class with the log file path as a command-line argument.

Example:

```bash
java Main data/access-smalllog
```
